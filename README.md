# quanttide-learn

量潮学习管理

## 概述

量潮学习管理（quanttide-learn）是量潮知识管理体系中的**学习管理**领域，以管理实践方式承载学习路径规划、学习过程跟踪与学习效果评估。

## 领域边界

- **学习路径**：学习目标拆解、课程路径与学习计划规划
- **学习过程**：学习进度跟踪、任务与测评管理
- **学习效果**：学习效果评估、反馈与持续改进

> 与 course 领域的分工：本领域承载「学习管理」（路径、进度、效果），course 承载「课程研发」（课程内容与工具）。
